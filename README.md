1. Задание: Модифицировать программу из л/р №1 для параллельной работы по технологии MPI. Провести серию экспериментов с разными размерами матриц (примерно 200, 400, 800, 1200, 1600, 2000), с разным количеством вычислительных ядер (1, 2, 4, 8 и т.д.).
2. Описание работы:
   Чтение и декомпозиция данных: чтение матриц из файлов и преобразование их в одномерные массивы для эффективной передачи через MPI.
   Распределение данных (MPI_Scatter): разделение строк первой матрицы ($A$) между всеми доступными вычислительными процессами.
   Рассылка данных (MPI_Bcast): передача полной копии второй матрицы ($B$) каждому процессу для обеспечения локальных вычислений.
   Параллельное вычисление: каждый процесс вычисляет свою порцию строк результирующей матрицы $C$ независимо от других.
   Сбор результата (MPI_Gather): объединение вычисленных блоков строк от всех процессов обратно в единую матрицу в главном процессе.
   Анализ производительности: измерение времени выполнения для различных конфигураций ядер (1, 2, 4, 6).
